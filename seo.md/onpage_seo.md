# 온페이지 SEO 최적화 전략

## 1. 기술적 SEO

### 1.1 URL 구조 최적화
- 메인 키워드 중심의 URL 설계
  - 예: `https://www.mungai.co.kr/ai-puppy-training`
  - 예: `https://www.mungai.co.kr/ai-puppy-training/apps`
  - 예: `https://www.mungai.co.kr/ai-puppy-training/guide`

### 1.2 이미지 최적화
- 파일명에 키워드 포함
  - 예: `ai-puppy-training-app.jpg`
  - 예: `smart-dog-training-technique.png`
- ALT 텍스트 최적화
  - 예: "강아지 훈련을 위한 AI 앱 인터페이스 예시"
  - 예: "AI 기반 스마트 강아지 훈련 방법"
- 이미지 압축을 통한 로딩 속도 향상

### 1.3 내부 링크 전략
- 관련 콘텐츠 간의 링크 연결
  - 예: `<a href="/ai-puppy-training/apps">AI 훈련 앱 비교 보기</a>`
  - 예: `<a href="/ai-puppy-training/guide">AI 훈련 초보자 가이드</a>`
- 앵커 텍스트에 키워드 활용

### 1.4 구조화된 데이터 적용
```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "AI로 강아지 훈련하기",
  "description": "AI 기반 강아지 훈련법과 추천 앱",
  "author": {
    "@type": "Person",
    "name": "펫 전문가"
  },
  "publisher": {
    "@type": "Organization",
    "name": "멍이AI",
    "logo": {
      "@type": "ImageObject",
      "url": "https://www.mungai.co.kr/logo.png"
    }
  }
}
```

## 2. 콘텐츠 최적화

### 2.1 제목 태그 최적화
- 각 페이지마다 고유한 타이틀 태그 작성
- 키워드를 앞부분에 배치
- 50-60자 이내로 유지

### 2.2 메타 설명 최적화
- 페이지 내용을 간결하게 요약
- 클릭 유도 문구 포함
- 150-160자 이내로 유지

### 2.3 헤딩 태그 구조화
- H1 태그는 페이지당 하나만 사용
- 계층적으로 H2, H3 태그 구성
- 키워드를 자연스럽게 포함

### 2.4 콘텐츠 내 키워드 배치
- 키워드 밀도를 1-2%로 유지
- 자연스러운 문맥 속에 키워드 배치
- LSI 키워드(연관 키워드) 활용

## 3. 사용자 경험(UX) 최적화

### 3.1 모바일 최적화
- 반응형 웹디자인 적용
- 모바일 사용자 경험 개선
- 터치 친화적인 인터페이스

### 3.2 페이지 로딩 속도 개선
- 이미지 최적화
- 불필요한 스크립트 제거
- 캐싱 활용
- CDN(Content Delivery Network) 사용

### 3.3 내비게이션 최적화
- 직관적인 메뉴 구조
- breadcrumbs 적용
- 검색 기능 제공

## 4. 콘텐츠 품질 향상

### 4.1 독창성 확보
- 원본 콘텐츠 우선 제공
- 외부 콘텐츠 사용 시 출처 명시
- 정기적인 콘텐츠 업데이트

### 4.2 사용자 참여 유도
- 댓글 기능 활성화
- 소셜 공유 버튼 추가
- 뉴스레터 구독 유도

### 4.3 접근성 향상
- ALT 태그 활용
- 명확한 콘텐츠 구조
- 적절한 폰트 크기와 색상 대비
